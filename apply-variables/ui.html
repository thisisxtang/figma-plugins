Auto apply layout variables from local or remote library

Click button below will auto apply variables to padding, spacing and border radius, icon size, colors properties of the selected elements.

The plugin will first use local variables and if there is none, then search library variables.

For layout specifications, it will also try to find the nearest (round down) variable value. E.g, the spacing is 9, it will apply 8 from the variable value.

Set color alias will assign color variable from remote library to the color variable local in the file

By doing this, when remote library color changes, your local colors variable will update accordingly, so to keep the colors consistent from the top main library down to all the design files

To use this you have to name the color collection in remote library to be "baseColors", and the local one to be "colors"
